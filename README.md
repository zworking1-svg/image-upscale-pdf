# Улучшение картинки ×4 и PDF для печати

Локальный сайт: загружаете картинку → нейросеть **Upscayl** увеличивает её в 4 раза → сайт делает PDF формата **A3** (также A4/A2) для печати в типографии.

## Из чего состоит

| Часть | Откуда |
|---|---|
| Увеличение ×4 | [upscayl/upscayl-ncnn](https://github.com/upscayl/upscayl-ncnn) (движок `upscayl-bin`) + модели из [upscayl/upscayl](https://github.com/upscayl/upscayl) |
| Конвертация в PDF | [img2pdf](https://gitlab.mister-muffin.de/josch/img2pdf) — встраивает картинку в PDF без пересжатия |
| Сайт | Python + Flask, сервер waitress |

Нужна видеокарта с поддержкой Vulkan (NVIDIA / AMD / Intel).

## Установка (один раз)

1. Установите Python 3.10+.
2. Запустите `setup.bat` — он создаст окружение, поставит библиотеки и скачает Upscayl с GitHub.

## Запуск

Запустите `start.bat` — откроется http://127.0.0.1:5000

## Советы для печати A3

- Для качественной печати нужно ~300 DPI: это примерно **3508×4961 px** для A3. Сайт показывает DPI до создания PDF.
- Картинка от 900×1250 px после увеличения ×4 уже даёт 300 DPI на A3.
- «Вписать целиком» — без обрезки (могут быть белые поля); «Заполнить лист» — без полей, края обрежутся.
- Если типография требует вылеты (bleed) или CMYK — уточните у них; обычно RGB-PDF принимают.
